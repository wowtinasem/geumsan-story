## 다음에 또 이식할 때를 위한 제안 (선택)

위 목록에서 보이듯 **지역 정보가 13개 파일에 흩어져 있습니다.** 부여→모산 때 잔재가 남은 이유가 이것이고, 금산→다음 지역도 똑같이 반복됩니다.

  appName: "금산 AI 동화 만들기",
  storageKey: "geumsan-ai-story.savedStories.v1",
  places: [ /* storyData.ts의 places */ ],
  settingBible: { /* server.js의 영문 묘사 */ },
