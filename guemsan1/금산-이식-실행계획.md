| `metadataBase` 임시값으로 배포 시 OG 이미지 URL 오류 | P6-5에서 반드시 확정값으로 교체 후 재배포 |
| 칠백의총 톤 제약이 Gemini에 안 먹을 수 있음 | P7에서 5건 이상 실측, 필요 시 문장 강화 또는 결말 선택지 필터링(후속) |
| `public/` 30MB 한계 | 새 이미지 3장 합계 ≤ 기존 3장(2.3MB) |

## 7. 후속 (이번 범위 밖, 여유 시)

- `src/story/regionConfig.ts`로 지역 정보 집약 (체크리스트 제안). 현재 **13개 파일 + 이번에 찾은 4개 = 17곳**에 흩어져 있음. 2~3시간 투자로 다음 이식이 "파일 1개 + 이미지 3장"으로 줄어듦. 프록시와 공유 방법(빌드 시 복사 vs JSON import)은 별도 결정.
- 칠백의총 선택 시 결말 선택지에서 "축하 파티" 항목을 UI에서 숨기기 (프롬프트 제약보다 확실함).
