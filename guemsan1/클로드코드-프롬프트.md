# Claude Code 붙여넣기용 프롬프트

아래 `---` 사이 전체를 복사해서 Claude Code에 그대로 붙여넣으세요.
**전제:** `geumsan-story` 저장소를 이미 클론했고, 그 폴더에서 Claude Code를 실행한 상태.

---

이 저장소는 초등학생이 AI로 6쪽 동화책을 만드는 수업용 웹앱이다. 원래 부여에서 만들어져 아산(모산초등학교)용으로 이식됐고, 이번에 **충남 금산 배경으로 다시 이식**한다.

## 구조 파악 먼저

- Next.js 앱(루트 `src/`) + Express 프록시(`story-proxy/`) 2단 구조
- 프록시가 Gemini를 호출해 동화 글·그림을 생성한다
- 작업 시작 전에 `README.md`, `작업기록.md`, `src/story/storyData.ts`, `story-proxy/server.js`를 먼저 읽어라

## 목표

아산 배경(현충사·외암민속마을)을 **금산 3곳**으로 바꾸고, 앱 전체에 남은 "모산"·"부여/Buyeo" 잔재를 전부 제거한다.

금산 3곳:
- 개삼터 인삼밭 (id/sceneKey: `gaesamteo`)
- 칠백의총 (id/sceneKey: `chilbaek`)
- 적벽강 (id/sceneKey: `jeokbyeok`)

## 반드시 지킬 규칙

1. **`.env` 파일은 절대 만들거나 수정하지 마라.** API 키·비밀번호를 코드나 문서에 쓰지 마라.
2. **단계별로 진행하고, 각 단계가 끝나면 멈춰서 무엇을 바꿨는지 보고하라.** 전부 한 번에 하지 마라.
3. 각 단계마다 `npm test`와 `npm run build`가 통과하는지 확인하라.
4. 단계별로 커밋을 나눠라. 커밋 메시지는 한국어로.
5. 확신이 안 서는 부분은 임의로 결정하지 말고 물어봐라.

## 1단계 — 장소 데이터 교체

### 1-1. `src/story/storyData.ts`

`places` 배열에서 `hyeonchungsa`, `oeam` 두 항목을 삭제하고 아래 3개를 추가:

```ts
{ id: "gaesamteo", name: "개삼터 인삼밭", sceneKey: "gaesamteo", color: "#4F8A3D", imageSrc: "/images/places/gaesamteo.png" },
{ id: "chilbaek", name: "칠백의총", sceneKey: "chilbaek", color: "#6B7A8F", imageSrc: "/images/places/chilbaek.png" },
{ id: "jeokbyeok", name: "적벽강", sceneKey: "jeokbyeok", color: "#B5603F", imageSrc: "/images/places/jeokbyeok.png" }
```

추가로 `sea`(반짝이는 바닷속) 항목을 **삭제**한다. 금산은 내륙 지역이라 어울리지 않고, 물 배경은 적벽강이 대신한다. 이러면 총 7곳이 유지되어 장소 선택 그리드 레이아웃이 그대로 맞는다.

`sea`를 지웠으면 관련 코드도 같이 정리해라:
- `src/story/StoryKioskApp.tsx`의 `scene === "sea"` 블록
- `story-proxy/server.js`의 `settingBible.sea`
- `public/images/places/sea.png`

### 1-2. `story-proxy/server.js` — `settingBible`

**이 항목이 그림 품질을 결정한다.** Gemini는 "Chilbaeguichong", "Gaesamteo" 같은 한국 고유명사를 모르기 때문에, 이름이 아니라 시각 묘사로 써야 한다. `hyeonchungsa`, `oeam` 항목을 지우고 아래를 넣어라:

```js
gaesamteo: "a sunlit Korean ginseng field in Geumsan, long rows of low plants under dark green shade screens on wooden frames, glossy leaves with clusters of bright red berries, forested mountain ridges behind, warm earthy soil",
chilbaek: "a quiet Korean memorial ground with a wide stone-paved courtyard, a tall stone monument, a low tiled-roof shrine gate, rows of tall pine trees, still and solemn morning light",
jeokbyeok: "a wide calm river curving beneath tall reddish-brown rock cliffs, pebbled riverbank, willow trees, mist over the water, soft golden late-afternoon light"
```

### 1-3. `story-proxy/server.js` — `buildPrompt`의 15번 항목

지금은 "현충사의 역사적 흔적이 단서가 된다 / 외암마을의 전통 생활 방식이…"로 되어 있다. **이걸 놓치면 배경만 금산이고 이야기 속 단서는 아산 것이 나온다.** 아래로 교체:

```
- 인삼밭의 그늘막과 붉은 열매가 사건의 단서가 된다.
- 칠백의총의 오래된 비석과 소나무가 이야기의 실마리를 준다.
- 적벽강의 붉은 절벽과 물길이 문제 해결에 영향을 준다.
```

### 1-4. 칠백의총 톤 제약 (중요)

칠백의총은 임진왜란 순국자를 기리는 위령 공간이다. 그런데 결말 선택지에 "작은 축하 파티를 열었어요" 같은 항목이 있어서 부적절한 조합이 나올 수 있다.

- `buildPrompt`의 고정값 블록에, 선택된 장소가 칠백의총일 때만 들어가는 조건부 문장을 추가해라:
  > 이 장소는 나라를 위해 목숨을 바친 분들을 기리는 곳이다. 추모하는 마음을 지키고, 소란스럽거나 가볍게 다루지 않는다. 파티나 장난 같은 요소는 넣지 않는다.
- `buildImagePrompt`에도 같은 취지의 영문 제약을 넣어라:
  > Keep the mood respectful and quiet; no party, no balloons, no playful chaos.

### 1-5. 장소 아이콘 도형

`src/story/StoryKioskApp.tsx`(대략 444~465행)에 CSS로 그린 작은 장소 아이콘이 있다. `scene === "hyeonchungsa"`, `scene === "oeam"` 블록을 금산 3곳으로 교체해라. 기존 블록들의 스타일 패턴을 그대로 따라라.

- `gaesamteo`: 초록 이랑 + 검은 그늘막 + 붉은 열매 점
- `chilbaek`: 회색 비석 기둥 + 소나무 실루엣
- `jeokbyeok`: 붉은 절벽 + 푸른 물결 띠

### 1-6. 배경 이미지

`public/images/places/`에 `gaesamteo.png`, `chilbaek.png`, `jeokbyeok.png`가 필요하다. **이 파일들은 내가 직접 준비할 테니 코드에서 경로만 맞춰두고, 파일이 없다는 점을 알려줘라.** 기존 `hyeonchungsa.png`, `oeam.png`는 삭제해라.

## 2단계 — 브랜딩 문자열 전수 교체

"모산초등학교" → 금산 학교명으로 바꿔야 한다. **학교 이름은 내가 알려줄 테니, 먼저 교체가 필요한 지점을 전부 찾아서 목록으로 보여주고 확인을 받아라.**

내가 파악한 지점은 아래와 같다. 빠진 곳이 있는지 직접 grep으로 재확인해라:

- `src/app/layout.tsx` — title.default, title.template, description, keywords, appleWebApp.title, openGraph.title, openGraph.siteName, twitter.title, 그리고 **`metadataBase`를 새 Vercel 주소로**
- `src/app/story/page.tsx` — description
- `src/app/opengraph-image.tsx` — `alt`, `heading`
- `src/story/StoryKioskApp.tsx` — `savedStoriesKey`(현재 `"buyeo-ai-story.savedStories.v1"` → `"geumsan-ai-story.savedStories.v1"`), `schoolLabel`, `coverHeading`
- `src/story/storyVideo.ts` — 영상 표지 자막 텍스트
- `src/story/pdfMetadata.ts` — `schoolLabel`
- `public/manifest.webmanifest` — name, short_name, description

`savedStoriesKey`는 특히 중요하다. 같은 태블릿으로 두 지역 앱을 쓰면 저장된 동화가 섞인다.

## 3단계 — 테스트 수정

`npm test`가 `vitest run src`라 통과하지 않으면 배포가 막힌다.

`src/story/pdfMetadata.test.ts`에 `place: "현충사"`와 기대값 `"소녀 가야의 현충사 모험"`, 모산 `schoolLabel`이 하드코딩되어 있다. 금산 값으로 고치고 `npm test` 전체를 통과시켜라.

## 4단계 — 부여(Buyeo) 잔재 제거

모산 버전이 부여 이름을 그대로 물려받은 부분이다. 이번에 끊어낸다.

- `install-buyeo-story.bat` → `install-geumsan-story.bat` (git mv로 파일명 변경 + 내부 문자열, 특히 바로가기 이름 `Buyeo AI Story.lnk`와 타깃 경로)
- `start-buyeo-story.bat` → `start-geumsan-story.bat` (내부 로그 문자열, 창 제목 포함)
- `stop-buyeo-story.bat` → `stop-geumsan-story.bat`
- `AI_CENTER_INSTALL.md` — 제목, 설치 경로 `C:\BuyeoAIStory`, 스크립트명 전부
- `README.md` — 제목, 설명, 스크립트명
- `story-proxy/README.md` — `# Buyeo Story Proxy`
- `story-proxy/package.json` — `"name": "buyeo-story-proxy"`
- `render.yaml` — `name: mosan-story-proxy` → `geumsan-story-proxy`
- `package.json` — `"name": "story-ideacube"`

마지막으로 `git grep -in "부여\|buyeo\|모산\|아산\|현충사\|외암\|hyeonchungsa\|oeam"`를 돌려서 `docs/`와 `작업기록.md`를 제외하고 남은 게 없는지 확인해라.

## 5단계 — 문서 갱신

`작업기록.md`를 금산 버전 기준으로 다시 써라. 기존 문서의 구조(구조 / 배포정보 / 접근설정 / 사용흐름 / 기능메모 / 로컬실행 / 환경변수 / 배포체크리스트 / 트러블슈팅)를 유지하되:

- 아산·모산 관련 서술을 금산으로 갱신
- 금산 3개 장소와 칠백의총 톤 제약을 "주요 기능/구현 메모"에 기록
- 배포 URL은 아직 모르니 `TODO`로 남겨라
- 비밀값은 절대 쓰지 마라
- `docs/superpowers/` 아래 모산 시절 계획 문서 3개는 그대로 두되, 과거 이력임을 `작업기록.md`에 한 줄 적어라
